# ved.ai Launch Page Aesthetic Guidelines (Astra Standard)

## 1. Visual Standards
- Surface: Ultra-dark zinc base (`#09090b`) with continuous radial spotlight gradients (`from-indigo-950/30 to-zinc-950`).
- Typography: Inter/Geist with tight letter-spacing (`tracking-tight`) for display headers; monospace JetBrains Mono for telemetry tags.
- Glassmorphism: `backdrop-blur-2xl` with subtle white borders (`border-white/[0.08]`).

## 2. Interactive Demonstrators
- The landing page must feature a live interactive preview of the dual-pane workbench with selectable tabs (`math`, `vision`, `telemetry`).
- Floating HUD visualizers must maintain active animation loops to demonstrate ambient AI presence.
